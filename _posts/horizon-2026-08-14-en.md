rss · IT之家 · Aug 13, 12:52

**「Background」** A harness is the layer that converts a language model into a working agent, handling context, tools, task state, feedback, and boundaries; DeepSeek has described this as &quot;Model + Harness = Agent.&quot; Harness v0.1 is built on Cordis, a meta-framework that only manages plugin loading, unloading, and dependencies, while every concrete component of the agent runtime is itself a Cordis plugin that communicates through services and events.

**「Impact」** The MIT-licensed model weights and Harness framework allow developers and enterprises to self-host the model and assemble custom agents on their own hardware, including domestic GPUs and generic accelerators, lowering private-deployment barriers and reducing dependence on a single cloud service.

Researchers from the University of California, San Diego \(UCSD\) and Oberlin College have developed a coin-sized, under-$100 device that can compromise a Boeing 737&\#x27;s flight management computer \(FMC\) by plugging into an unlocked maintenance port in the aircraft&\#x27;s exterior electronics bay. Presented on August 13 at the USENIX Security Symposium in Baltimore, the attack uses a technique called &quot;Bus Driver&quot; to send stronger electrical signals that intercept, alter, and forge commands traveling between the FMC and the cockpit&\#x27;s multifunction control display unit \(MCDU\). In demonstrations, the device modified takeoff weight and outside air temperature readings within 60 seconds, which could cause the FMC to calculate insufficient takeoff thrust, and it could slightly change flight-plan waypoints to gradually divert the aircraft from its intended route. The device includes a Wi-Fi module for remote control. The team spent years assembling second-hand avionics into a test platform named Triton, disclosed the vulnerability to Boeing in 2020, and later demonstrated it in Boeing&\#x27;s laboratory; Boeing responded that existing layered protections sufficiently limit real-world feasibility, while the researchers suggest sealing or removing the port but do not call for grounding Boeing 737s.

rss · IT之家 · Aug 13, 12:43

**「Background」** The flight management computer \(FMC\) is a central avionics component that calculates flight performance data, such as optimal thrust settings and navigation routes, using inputs like aircraft weight, outside air temperature, and flight plan waypoints. The cockpit&\#x27;s multifunction control display unit \(MCDU\) is the crew interface for entering and viewing this data. An exterior electronics bay on the Boeing 737 contains maintenance ports used by ground crews to test and diagnose avionics equipment; under normal procedures these compartments may be left unlocked on the ground.

**「Impact」** The research demonstrates that a low-cost physical device inserted into a 737&\#x27;s electronics bay could alter critical FMC data used for takeoff performance and navigation, highlighting a potential ground-security vulnerability for airlines and airport operators; no real-world attacks have been reported, Boeing maintains that existing safeguards are adequate, and trained pilots could manually override the flight controls using independent cockpit displays.

**「Impact」** Engineers designing AI memory architectures should treat storage and memory as separate concepts and build an explicit write-side curation layer with provenance checks, rather than assuming a vector database alone provides durable memory.
